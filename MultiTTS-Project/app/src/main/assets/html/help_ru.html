Основные операции

  • Нажмите коротким нажатием на голос чтобы выбрать/отменить голос (до появления на голосе синей полоски). Голос будет выбран на роль главного диктора в синтезе речи.
  • Длительное нажатие на голос перед иконкой наушника чтобы выбрать/отменить голос (до появления на голосе зелёной полоски). Голос будет выбран на роль диалога в синтезе речи.
  • Длительное нажатие на иконку голоса для редактирования настроек голоса (скорость/громкость/тон).
  • Длительное нажатие на иконке оффлайн/онлайн, чтобы удалить голос.
  • Нажмите и удерживайте имя голоса, перетаскивайте вверх/вниз для сортировки.
  • Нажмите и удерживайте имя голоса, сдвигайте имя голоса влево/вправо, чтобы удалить.
  • Для других списков: сдвигайте влево/вправо для удаления, перетаскивайте вверх/вниз для сортировки.
  • На основном экране программы потяните пальцем вниз, чтобы отобразить интерфейс пакетного управления (выбор/удаление/экспорт/роль).

Описание функций

  • Импорт данных: Выберите архив, содержащий поддерживаемые данные движка синтеза, для импорта. Корневая папка в ZIP-архиве должна содержать корректный файл config.yaml.
  • Замена: В этом интерфейсе можно корректировать произношение слов. Поддерживается как обычная замена, так и регулярные выражения.
  • Фоновая музыка: Воспроизведение фоновой музыки во время синтеза речи.
  • Управление ролями: Добавление правил для распознавания ролей в тексте и использование заданных голосов для их воспроизведения.
  • Группа голосов: Для каждого конкретного персонажа, соответствующего абстрактной роли, выбирается голос из группы голосов и назначается этому персонажу.
  • Управление TTS модулями: Редактирование, добавление, удаление, сортировка и экспорт данных TTS модулей.
  • Перезагрузка данных: Перечитать файл конфигурации и загрузить данные. По умолчанию данные загружаются из базы данных.

Управление ролями

  • Имя роли: Имя роли для сопоставления.
  • Регулярное выражение роли: Регулярное выражение для сопоставления имени роли. Если не указано, используется имя роли.
  • Абстрактная роль: Если не включено, все совпадающие персонажи будут использовать один и тот же голос; если включено, это означает, что это абстрактная роль (соответствующая нескольким конкретным персонажам), и каждый конкретный персонаж будет использовать голос из группы голосов.
  • Поиск совпадения с просмотром вперёд: Правило будет соответствовать тексту перед разговором.
  • Поиск совпадения с просмотром назад: Правило будет соответствовать тексту после разговора.
  • Режим сопоставления:
    • Текст: Сопоставляет весь текст, соответствующий регулярному выражению.
    • Язык: Сопоставляет текст для выбранного языка.
    • Роль: Установите соответствие между диктором и содержанием диалога.
  • Программа сначала выполнит все прямые совпадения, а обратные совпадения выполнит только в случае отсутствия результатов от прямых совпадений.
  • В интерфейсе управления ролями нажмите и удерживайте кнопку "Добавить", чтобы добавить кандидатов на роль носителей языка.

Управление TTS модулями

  • Тип: Тип модуля. В настоящее время можно добавить только TTS модуль HTTP.
  • Код: Внутреннее представление TTS модуля. Пожалуйста, используйте буквенно-цифровые символы и символ подчеркивания.
  • Заголовок запроса: Заголовок запроса, используемый при отправке HTTP-запроса.
  • URL: HTTP-ссылка. Пожалуйста, заключайте выражения javascript в {{}}.
  • Поддерживаемые значения в кавычках в URL-адресах:
    • voiceCode: Код диктора.
    • speakText: Синтезируемый текст.
    • speakSpeed: Скорость речи, диапазон значений 0~100.
    • speakVolume: Громкость, диапазон значений 0~100.
    • params: Массив параметров, соответствующий параметрам диктора, которые были сегментированы.

Группа голосов

  • Абстрактная роль: Абстрактная роль, определенная в управлении ролями.
  • Голос персонажа: Каждое конкретное лицо, соответствующее абстрактному персонажу, будет иметь один голос, выбранный из голосов в той же группе, назначенной ему.

Настройки

  • Правила сопоставления ролей: Используются для отсеивания легальных контекстов при сопоставлении диалоговых ролей. Используйте __ROLE__ для обозначения роли, которую нужно сопоставить, и __OTHER__ для обозначения других ролей.
  • Анализ грамматической структуры (поддерживается только китайский язык): Введите фрагмент текста, пометьте его частями речи и получите грамматическую структуру предложения. Таблицу частей речи смотрите в конце справки.
  • Автоматическое назначение голосов: После распознавания персонажа, автоматически выбирайте голоса из группы ролей (сначала необходимо определить абстрактные роли и настроить группу ролей). Соответствие будет сохранено в кэше до тех пор, пока не будет перезаписано новой записью.
  • Анализ текстовых символов (поддерживается только китайский язык): Анализ новых слов в тексте. Процесс анализа довольно долгий. После завершения анализа нажмите "Сохранить", чтобы создать символ в управлении символами.
  • Регулярное выражение для имени персонажа: используется для фильтрации новых слов, проанализированных в тексте, при анализе символов, чтобы отфильтровать имена.

Перенаправление

  • Text-to-Speech интерфейс ( http://localhost:8774/forward ), GET параметры:
    • text: Синтезируемый текст.
    • speed: Скорость речи, диапазон значений 0~100.
    • volume: Громкость, диапазон значений 0~100.
    • pitch: Тон, диапазон значений 0~100.
    • voice: идентификатор голоса, используйте конечную точку /voices, чтобы получить всех доступных дикторов.
  • Интерфейс списка голосов ( http://localhost:8774/voices ), без параметров.
Пользовательские теги
  • [[Custom Tag]] Содержимое, в таком формате, будет обрабатываться как тег и не будет озвучено.
  • [[PAUSE:1000]] Обозначает паузу в 1000мс.
  • [[SPEED:1.2]] Устанавливает скорость речи в 1.2 раза выше стандартной.
  • [[PITCH:1.2]] Устанавливает тон в 1.2 раза выше чем стандартный.
  • [[VOLUME:1.2]] Устанавливает громкость в 1.2 раза выше чем стандартная.
    • Прочее
  • Чтобы вручную указать говорящего в тексте, заключите его имя в двойные угловые скобки <<>> внутри кавычек. Пример: "<<Джон>>Эту фразу произношу я."
  • Если приложение выгружается в фоновом режиме, установите такие разрешения, как оптимизация батареи, фоновый режим, автозапуск и предотвращение перехода в спящий режим (в зависимости от телефона).
  • Если сообщение об ошибке содержит ключевое слово zip при импорте архива, возможно, произошла ошибка при загрузке архива.
  • При сбое программы журнал будет скопирован в буфер обмена. Пожалуйста, приложите полный журнал при сообщении о проблеме.

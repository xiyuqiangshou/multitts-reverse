Grundläggande användning

  • Tryck för att välja/avmarkera huvudmotorn för syntes
  • Långtryck för att välja/avmarkera dialogmotorn
  • Långtryck på avataren för att redigera talaren
  • Långtryck på online/offline-ikonen för att ta bort talaren
  • Håll nere talarens namn och dra upp eller ner för att sortera
  • Håll nere talarens namn och svep vänster eller höger för att ta bort
  • För andra listor: svep vänster/höger för att ta bort, dra upp/ner för att sortera
  • I huvudgränssnittet: dra ner från toppen av listan för att visa batchhantering

Funktionsbeskrivning

  • Importera data: välj en zip-fil med stödda motordata. Den måste innehålla en giltig config.yaml i roten.
  • Ersättning: korrigera uttalet av ord i detta gränssnitt. Stöd för både normal och reguljär ersättning.
  • Bakgrundsmusik: spela musik under talsyntesen.
  • Rollhantering: lägg till regler för att identifiera roller i texten och tilldela talare.
  • Röstpool: för varje karaktär som matchar en abstrakt roll väljs en röst från poolen.
  • Motorhantering: redigera, lägg till, ta bort, sortera och exportera motorer.
  • Ladda om data: läs om konfigurationsfilen och ladda data. Standard från databasen.

Rollhantering

  • Rollnamn: namnet på rollen att matcha.
  • Reguljärt uttryck: matchar rollnamnet. Om tomt används rollnamnet.
  • Abstrakt roll: om avaktiverad använder alla karaktärer samma röst. Om aktiverad får varje karaktär en röst från poolen.
  • Framåtsmatch: regeln matchar text före dialogen.
  • Bakåtsmatch: regeln matchar text efter dialogen.
  • Matchläge:
    • Text: matchar allt innehåll som överensstämmer med uttrycket.
    • Språk: matchar text som motsvarar valt språk.
    • Roll: matchar dialogens talare.
  • Programmet utför först alla framåtmatchningar, och endast om inga resultat hittas utförs bakåtmatchningar.
  • I rollhanteringen: långtryck på Lägg till-knappen för att lägga till språk-talare.

Motorhantering

  • Typ: motortyp. För närvarande stöds endast HTTP-motorer.
  • Kod: intern representation. Använd endast bokstäver, siffror och understreck.
  • Begärandehuvud: header som används vid HTTP-begäran.
  • URL: HTTP-länk. Lägg JavaScript-uttryck inom {{}}.
  • Stödda värden i URL:
    • voiceCode: röstkod
    • speakText: text att syntetisera
    • speakSpeed: hastighet, 0–100
    • speakVolume: volym, 0–100
    • params: parameterlista motsvarande talarens parametrar

Röstpool

  • Abstrakt roll: definierad i rollhanteringen.
  • Karaktärsröst: varje karaktär som matchar rollen får en röst från samma grupp.

Inställningar

  • Rollmatchningsregler: används för att filtrera giltiga kontexter. _ROLE_ avser rollen och _OTHER_ andra roller.
  • Grammatisk analys (endast kinesiska): analyserar en text och dess struktur.
  • Automatisk tilldelning av röster: efter identifiering tilldelas automatiskt röster från poolen. Lagrade i cache.
  • Textanalys (endast kinesiska): analysera nya ord. Klicka på Spara för att generera karaktärer.
  • Reguljärt uttryck för namn: filtrerar bort namn från analysen.

Vidarebefordran

  • TTS-gränssnitt ( http://localhost:8774/forward ), GET-parametrar:
    • text: text att syntetisera
    • speed: hastighet, 0–100
    • volume: volym, 0–100
    • pitch: tonhöjd, 0–100
    • voice: röst-ID, använd /voices för att få alla tillgängliga röster
  • Röstlista ( http://localhost:8774/voices ), inga parametrar.

Anpassade taggar

  • [[Custom Tag]] Innehåll i detta format behandlas som tagg och syntetiseras inte.
  • [[PAUSE:1000]] Paus i 1000 ms.
  • [[SPEED:1.2]] Ställer in hastigheten till 1,2.
  • [[PITCH:1.2]] Ställer in tonhöjden till 1,2.
  • [[VOLUME:1.2]] Ställer in volymen till 1,2.

Övrigt

  • För att manuellt ange talare i texten, sätt namnet inom <<>>. Exempel: "<<Johan>>Denna mening sägs av mig."
  • Om appen stängs i bakgrunden, aktivera tillstånd som batterioptimering, bakgrundskörning, autostart och förhindra viloläge (beroende på enhet).
  • Om felmeddelandet innehåller “zip” vid import kan nedladdningen ha misslyckats.
  • Vid krascher kopieras loggen till urklipp. Inkludera den vid felrapportering.
  • Nuvarande version: v_VERSION_NAME_
  • Android-ID: _ANDROID_ID_

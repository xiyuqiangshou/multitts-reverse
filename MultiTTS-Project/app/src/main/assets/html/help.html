Basic Operation

  • Click to select/deselect the main synthesis engine
  • Long press to select/deselect the dialogue synthesis engine
  • Long press the avatar to edit the speaker
  • Long press the offline/online icon to delete the speaker
  • Press and hold the speaker's name and drag it up or down to sort
  • Press and hold the speaker's name and slide left and right to delete
  • For other lists, slide left and right to delete, drag up and down to sort
  • The main interface pulls down at the top of the list to display the batch management interface

Function Description

  • Import data: Select a compressed package containing supported engine data to import. The first layer of the zip file must contain a valid config.yaml file.
  • Replacement: The pronunciation of words can be corrected in this interface, which supports both normal replacement and regular replacement.
  • Background music: Play background music while synthesizing speech.
  • Role management: Add rules to identify roles in the text to be read aloud and use specified speakers to read aloud.
  • Voice Pool: For each specific character that matches an abstract role, a voice is selected from the voice pool and assigned to that character.
  • Engine management: edit, add, delete, sort and export data for engines.
  • Reload data: Reread the configuration file and load the data. By default, it is loaded from the database.

Role Management

  • Role Name: The name of the role to match.
  • Role regular expression: A regular expression that matches the role name. If not filled in, the value of the role name is used.
  • Abstract role: When not enabled, all matching characters will use the same voice; when enabled, it means that this is an abstract role (corresponding to multiple specific characters), and each specific character will draw a voice from the voice pool.
  • Lookahead match: The rule will match the text before the conversation.
  • Lookbehind match: The rule will match the text after the conversation.
  • Match Mode:
    • Text: Match all text content that conforms to the regular expression.
    • Language: Match text that corresponds to the selected language.
    • Role: Match the speaker of the dialogue content.
  • The software will first perform all forward matches, and only perform backward matches when there are no results from the forward matches.
  • In the role management interface, long press the Add button to add candidate language speakers.

Engine Management

  • Type: Engine type. Currently, only the http engine can be added.
  • Code: The internal representation of the engine. Please use alphanumeric characters and underscores.
  • Request header: The request header used when sending an http request.
  • URL: http link. Please enclose javascript expressions in {{}}.
  • Supported quoted values in URLs:
    • voiceCode: speaker code
    • speakText: The text to be synthesized
    • speakSpeed: speaking speed, value range 0~100
    • speakVolume: volume, value range 0~100
    • params: parameter array, corresponding to the speaker's parameters, which have been segmented

Voices Pool

  • Abstract role: abstract role defined in role management.
  • Character Voice: Each specific person corresponding to the abstract character will have one voice selected from the voices in the same group assigned to it.

Settings

  • Role matching rules: used to filter out legal contexts when matching dialogue roles. Use __ROLE__ to refer to the role to be matched, and __OTHER__ to refer to other roles.
  • Grammatical structure analysis (Only supports Chinese): Input a piece of text, tag the text with parts of speech, and obtain the sentence grammatical structure. For the part of speech table, please refer to the end of the help.
  • Automatically assign voices: After recognizing a person, automatically select voices from the role pool (you need to define abstract roles and set up the role pool first). The assignment relationship will be cached until it is overwritten by a new record.
  • Text character analysis (Only supports Chinese): Analyze new words in the text. The analysis process is relatively long. After the analysis is completed, click Save to generate the character in the character management.
  • Character name regular expression: used to filter out new words analyzed in text character analysis to filter out names.

Forwarder

  • Text-to-Speech Interface ( http://localhost:8774/forward ), GET parameters:
    • text: Text to be synthesized
    • speed: Speech rate, value range 0~100
    • volume: Volume level, value range 0~100
    • pitch: Pitch level, value range 0~100
    • voice: Voice ID, use /voices endpoint to get all available speakers
  • Voice List Interface ( http://localhost:8774/voices ), no parameters.

Custom Tags

  • [[Custom Tag]] Content wrapped in this format will be treated as a tag and will not be synthesized.
  • [[PAUSE:1000]] Indicates a pause of 1000ms.
  • [[SPEED:1.2]] Sets the speech rate to 1.2 times the default.
  • [[PITCH:1.2]] Sets the pitch to 1.2 times the default.
  • [[VOLUME:1.2]] Sets the volume to 1.2 times the default.

Others

  • To manually specify the speaker in the text, wrap the speaker's name with <<>> inside the quotation marks. Example: "<<John>>This sentence is spoken by me."
  • If the app is killed in the background, please set permissions such as battery optimization, background running, associated startup, and prevent sleep (depending on the phone).
  • If the error message contains the keyword zip when importing a compressed package, an error may have occurred while downloading the compressed package.
  • When the software crashes, the log will be copied to the clipboard. Please attach the complete log when reporting the problem.

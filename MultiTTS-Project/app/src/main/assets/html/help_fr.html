Opérations de base

  • Appuyer pour sélectionner/désélectionner le moteur principal de synthèse
  • Appui long pour sélectionner/désélectionner le moteur de synthèse de dialogue
  • Appui long sur l’avatar pour modifier le locuteur
  • Appui long sur l’icône hors ligne/en ligne pour supprimer le locuteur
  • Maintenir le nom du locuteur et le faire glisser vers le haut ou vers le bas pour trier
  • Maintenir le nom du locuteur et le faire glisser vers la gauche ou la droite pour supprimer
  • Pour les autres listes, glisser à gauche ou à droite pour supprimer, glisser vers le haut ou le bas pour trier
  • Tirer vers le bas en haut de la liste de l’interface principale pour afficher l’interface de gestion par lots

Description des fonctions

  • Importer des données : sélectionner un fichier compressé contenant des données de moteur prises en charge. Le premier niveau du fichier zip doit contenir un fichier config.yaml valide.
  • Remplacement : corriger la prononciation des mots dans cette interface, prend en charge le remplacement normal et régulier.
  • Musique de fond : jouer de la musique de fond pendant la synthèse vocale.
  • Gestion des rôles : ajouter des règles pour identifier les rôles dans le texte à lire et utiliser des locuteurs spécifiques.
  • Pool de voix : pour chaque personnage correspondant à un rôle abstrait, une voix est choisie dans le pool et attribuée.
  • Gestion des moteurs : modifier, ajouter, supprimer, trier et exporter des données de moteurs.
  • Recharger les données : relire le fichier de configuration et charger les données. Par défaut, chargées depuis la base de données.

Gestion des rôles

  • Nom du rôle : le nom du rôle à faire correspondre.
  • Expression régulière du rôle : expression régulière correspondant au nom du rôle. Si non rempli, le nom du rôle est utilisé.
  • Rôle abstrait : si désactivé, tous les personnages correspondants utilisent la même voix ; si activé, chaque personnage spécifique reçoit une voix différente du pool.
  • Correspondance anticipée : la règle correspond au texte avant la conversation.
  • Correspondance arrière : la règle correspond au texte après la conversation.
  • Mode de correspondance :
    • Texte : correspond à tout contenu textuel conforme à l’expression régulière.
    • Langue : correspond au texte correspondant à la langue sélectionnée.
    • Rôle : correspond au locuteur du dialogue.
  • Le logiciel effectue d’abord toutes les correspondances anticipées. Les correspondances arrière ne sont effectuées que s’il n’y a pas de résultats.
  • Dans l’interface de gestion des rôles, appui long sur le bouton Ajouter pour ajouter des locuteurs candidats pour les langues.

Gestion des moteurs

  • Type : type de moteur. Actuellement, seul le moteur HTTP peut être ajouté.
  • Code : représentation interne du moteur. Utilisez uniquement des caractères alphanumériques et des traits de soulignement.
  • En-tête de requête : en-tête utilisé lors de l’envoi d’une requête HTTP.
  • URL : lien HTTP. Encadrez les expressions JavaScript dans {{}}.
  • Valeurs prises en charge dans les URL :
    • voiceCode : code du locuteur
    • speakText : texte à synthétiser
    • speakSpeed : vitesse, plage de 0 à 100
    • speakVolume : volume, plage de 0 à 100
    • params : tableau de paramètres correspondant aux paramètres du locuteur

Pool de voix

  • Rôle abstrait : rôle abstrait défini dans la gestion des rôles.
  • Voix du personnage : chaque personnage spécifique correspondant au rôle abstrait reçoit une voix du même groupe.

Paramètres

  • Règles de correspondance des rôles : utilisées pour filtrer les contextes légaux lors de la correspondance. Utilisez _ROLE_ pour désigner le rôle et _OTHER_ pour les autres rôles.
  • Analyse de la structure grammaticale (supporte uniquement le chinois).
  • Attribution automatique des voix : après reconnaissance, attribue automatiquement une voix du pool (rôles abstraits requis). L’attribution est mise en cache jusqu’à écrasement.
  • Analyse des caractères du texte (uniquement chinois) : détecter de nouveaux mots. Cliquer sur Enregistrer pour générer un nouveau personnage.
  • Expression régulière des noms : filtrer les nouveaux mots analysés pour garder uniquement les noms.

Transfert

  • Interface TTS ( http://localhost:8774/forward ), paramètres GET :
    • text : texte à synthétiser
    • speed : vitesse, 0~100
    • volume : volume, 0~100
    • pitch : hauteur, 0~100
    • voice : ID de la voix, utiliser /voices pour obtenir toutes les voix disponibles
  • Interface liste des voix ( http://localhost:8774/voices ), aucun paramètre.

Balises personnalisées

  • [[Custom Tag]] Le contenu entre ce format est traité comme balise et non synthétisé.
  • [[PAUSE:1000]] Pause de 1000 ms.
  • [[SPEED:1.2]] Définit la vitesse à 1,2.
  • [[PITCH:1.2]] Définit la hauteur à 1,2.
  • [[VOLUME:1.2]] Définit le volume à 1,2.

Autres

  • Pour indiquer manuellement le locuteur dans le texte, insérer le nom entre <<>>. Exemple : "<<Jean>>Cette phrase est dite par moi."
  • Si l’application est arrêtée en arrière-plan, ajuster les paramètres d’optimisation batterie, exécution arrière-plan, démarrage automatique et veille (selon l’appareil).
  • Si un message d’erreur contient « zip » lors de l’importation, une erreur est survenue lors du téléchargement.
  • En cas de crash, le journal est copié dans le presse-papiers. Veuillez l’envoyer avec le rapport.
  • Version actuelle : v_VERSION_NAME_
  • ID Android : _ANDROID_ID_

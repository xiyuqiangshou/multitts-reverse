Operación básica

  • Haga clic para seleccionar/deseleccionar el motor de síntesis principal.
  • Mantenga pulsado para seleccionar/deseleccionar el motor de síntesis de diálogos.
  • Mantenga presionado el avatar para editar el hablante.
  • Mantenga presionado el ícono fuera de línea/en línea para eliminar el altavoz
  • Mantenga presionado el nombre del orador y arrástrelo hacia arriba o hacia abajo para ordenar
  • Mantenga presionado el nombre del orador y deslícelo hacia la izquierda y hacia la derecha para eliminarlo.
  • Para otras listas, deslice hacia la izquierda y hacia la derecha para eliminar, arrastre hacia arriba y hacia abajo para ordenar
  • La interfaz principal se despliega en la parte superior de la lista para mostrar la interfaz de administración de lotes.

Función descriptiva

  • Importar datos: seleccione un paquete comprimido que contenga datos de motor compatibles para importar. La primera capa del archivo zip debe contener un archivo config.yaml válido.
  • Reemplazo: la pronunciación de las palabras se puede corregir en esta interfaz, que admite tanto el reemplazo normal como el reemplazo regular.
  • Música de fondo: reproduzca música de fondo mientras sintetiza la voz.
  • Gestión de roles: agregue reglas para identificar roles en el texto que se leerá en voz alta y utilice hablantes específicos para leer en voz alta.
  • Grupo de voces: para cada personaje específico que coincide con un rol abstracto, se selecciona una voz del grupo de voces y se asigna a ese personaje.
  • Gestión de motores: edite, agregue, elimine, ordene y exporte datos para motores.
  • Recargar datos: Vuelva a leer el archivo de configuración y cargue los datos. Por defecto, se carga desde la base de datos.

Gestión de roles

  • Nombre del rol: el nombre del rol que debe coincidir.
  • Expresión regular de rol: una expresión regular que coincide con el nombre del rol. Si no se completa, se utiliza el valor del nombre del rol.
  • Rol abstracto: cuando no está habilitado, todos los personajes coincidentes usarán la misma voz; cuando está habilitado, significa que se trata de un rol abstracto (correspondiente a varios personajes específicos) y cada personaje específico extraerá una voz del grupo de voces.
  • Coincidencia anticipada: la regla coincidirá con el texto anterior a la conversación.
  • Coincidencia de búsqueda retrospectiva: la regla coincidirá con el texto después de la conversación.
  • El software primero realizará todos los partidos hacia adelante y solo realizará partidos hacia atrás cuando no haya resultados de los partidos hacia adelante.
  • En la interfaz de administración de funciones, mantenga presionado el botón Agregar para agregar hablantes de idiomas candidatos.

Mantenimiento de el motor

  • Tipo: Tipo de motor. Actualmente, sólo se puede agregar el motor http.
  • Código: La representación interna del motor. Utilice caracteres alfanuméricos y guiones bajos.
  • Encabezado de solicitud: el encabezado de solicitud utilizado al enviar una solicitud http.
  • URL: enlace http. Por favor incluya expresiones javascript en {{}}.
  • Valores citados admitidos en URL:
    • voiceCode: código de altavoz
    • SpeakText: El texto a sintetizar.
    • SpeakSpeed: velocidad de habla, rango de valores 0~100
    • talkVolume: volumen, rango de valores 0~100
    • params: matriz de parámetros, correspondiente a los parámetros del hablante, que han sido segmentados

Piscina de voces

  • Rol abstracto: rol abstracto definido en la gestión de roles.
  • Voz del Personaje: Cada persona concreta correspondiente al personaje abstracto tendrá una voz seleccionada entre las voces del mismo grupo que tiene asignadas.

Ajustes

  • Reglas de coincidencia de roles: se utilizan para filtrar contextos legales al hacer coincidir roles de diálogo.
  • Análisis de la estructura gramatical (solo admite chino): ingrese un fragmento de texto, etiquete el texto con partes de la oración y obtenga la estructura gramatical de la oración. Para conocer la tabla de partes del discurso, consulte el final de la ayuda.
  • Asigne voces automáticamente: después de reconocer a una persona, seleccione automáticamente voces del grupo de roles (primero debe definir roles abstractos y configurar el grupo de roles). La relación de asignación se almacenará en caché hasta que un nuevo registro la sobrescriba.
  • Análisis de caracteres de texto (solo admite chino): analiza nuevas palabras en el texto. El proceso de análisis es relativamente largo. Una vez completado el análisis, haga clic en Guardar para generar el personaje en la gestión de personajes.
  • Expresión regular de nombre de carácter: se utiliza para filtrar nuevas palabras analizadas en el análisis de caracteres de texto para filtrar nombres.
